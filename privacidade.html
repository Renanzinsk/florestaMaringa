Política de Privacidade

Última atualização: 10 de junho de 2026

Esta Política de Privacidade descreve como o projeto Mapa de Árvores coleta, usa, armazena e protege os dados pessoais dos usuários, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD - Lei nº 13.709/2018).

1. Dados Coletados

Coletamos os seguintes dados pessoais durante o cadastro:

  • Nome completo — para identificação do usuário nas avaliações
  • E-mail — para autenticação e comunicação
  • Senha — armazenada de forma segura com hash criptográfico (BCrypt)

Comentários em avaliações são fornecidos voluntariamente e podem conter dados pessoais.

2. Base Legal

O tratamento dos dados é baseado no consentimento do titular (Art. 7º, I da LGPD), manifestado no momento do cadastro ao aceitar esta política.

3. Finalidade do Tratamento

  • Autenticação e gerenciamento de conta
  • Permitir que usuários avaliem árvores na plataforma
  • Exibir publicamente o nome do autor junto com sua avaliação
  • Segurança do sistema (rate limiting, logs operacionais)

4. Compartilhamento de Dados

Os dados pessoais não são vendidos ou compartilhados com terceiros para fins comerciais.

Serviços de terceiros utilizados pela plataforma:

  • OpenStreetMap — mapas e tiles (dados de navegação como IP e coordenadas visíveis)
  • unpkg.com — CDN para bibliotecas JavaScript (Leaflet, Supercluster)

5. Direitos do Titular

Você pode, a qualquer momento:

  • Acessar seus dados pessoais
  • Corrigir dados incompletos ou desatualizados
  • Excluir sua conta e dados associados
  • Solicitar a portabilidade dos dados
  • Revogar o consentimento a qualquer momento

6. Armazenamento e Segurança

Os dados são armazenados em banco de dados PostgreSQL. Senhas são protegidas com hash BCrypt. Tokens de autenticação JWT são armazenados em cookies HTTP-only com atributos de segurança (Secure, SameSite).

7. Retenção de Dados

Os dados são mantidos enquanto a conta estiver ativa. Ao excluir a conta, os dados pessoais são removidos. Avaliações anônimas podem permanecer para fins de integridade do sistema.

8. Contato

Para exercer seus direitos ou esclarecer dúvidas sobre esta política, entre em contato pelo e-mail disponível na seção "Sobre" da plataforma.

9. Alterações nesta Política

Esta política pode ser atualizada periodicamente. Recomendamos revisá-la regularmente. O uso continuado da plataforma após alterações constitui aceitação da versão vigente.
